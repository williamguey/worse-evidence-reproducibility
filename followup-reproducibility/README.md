# Offline H01 scientific reproduction

This is a documented publication projection. Original private records and the
existing canonical baseline remain unchanged. The bundle contains no study
spending amounts, payment reservations, ledger, credentials, reasoning traces,
private notes, review documents or collection transport. Fictional report costs
in the decision tasks and published endpoint unit prices are scientific inputs.
Receipt projections retain the independently audited charge-known Boolean so
the frozen scorer's missingness rule is preserved without inventing a payment.

Run `python3 -B offline_reproduce.py` from this directory, using Python3.9 or
later and its standard library. `original/` reproduces the original H01 Holm2
cohort. `followup/` reproduces the retired DeepInfra V5 panel; `baidu/` reproduces
the new Baidu panel and the paper's ten-endpoint union. The original 832 Luna
assignments appear in both stage panels as exact reuse, with one Luna endpoint
in Holm10. Both follow-up panels use the same96 cases; there are no new
independent case clusters. Missing cells keep fixed weights. Native Holm4
panels are intermediate artifacts. CoreWeave contributes only immutable
sanitized terminal provenance and three unavailable p1/full-support endpoints.

Reproduction rewrites derived JSON under each cohort's results/. Copy the bundle
if retaining the distributed files unchanged is useful. Its original hashes,
public hashes and transformations are in provenance/publication-manifest.json;
these explicitly distinguish projected records from original collected records.
The original H01 scientific analyzer and both frozen inference implementations
are byte-identical to their sources. Follow-up scorers change only their receipt
known-charge test to the audited Boolean. Public endpoint/stage comparisons are
descriptive and do not identify a provider's causal effect or a model population.

`baidu/provenance/speed-amendment.json` retains allowlisted cutoff commitments,
logical admissions/completions, eight total/four per-mode workers, minimum
one-second admission spacing and contiguous-prefix circuit metadata. It asserts
no physical wire order. Original five-second pacing evidence remains separate.
No paid replication or upload is performed by the reproduction command.
